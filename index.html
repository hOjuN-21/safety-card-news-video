사용 가이드 & GitHub 배포 방법

1. 카드 뉴스 등록

안전 카드 이미지(PNG, JPG)를 드래그하여 등록하고, 각 카드에 읽어줄 나레이션 대본을 입력합니다.

2. AI 음성 및 BGM 설정

선호하는 성우 목소리와 나레이션 속도를 조절하고, 자막 디자인과 어울리는 배경음악을 선택합니다.

3. 원클릭 MP4 생성 및 다운로드

[MP4 동영상 제작하기] 버튼을 누르면 고화질 동영상이 브라우저 내에서 즉시 렌더링되어 다운로드할 수 있습니다.

GitHub Pages 배포 안내

이 프로젝트는 100% 정적 웹앱으로 구성되어 있어, GitHub 저장소에 Push 후 Settings -> Pages에서 `main` 브랜치를 선택하기만 하면 전사 직원 누구나 웹 링크로 바로 접속해 사용할 수 있습니다.
